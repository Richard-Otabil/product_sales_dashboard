# Product Sales Performance Dashboard | 2023–2024

## Overview
An interactive Power BI dashboard built on a dataset of 200,000 US product 
sales transactions spanning January 2023 to December 2024. The dashboard 
enables business stakeholders to monitor sales performance, track 
profitability, and identify regional and category-level trends through 
interactive filtering and multi-page navigation.

## Dashboard Pages
| Page | Purpose |
|---|---|
| **Overview** | High-level KPIs and trend analysis |
| **Category Analysis** | Product category and sub-category performance |
| **Regional Analysis** | Geographic revenue and profit breakdown |

## Key KPIs Tracked
- Total Revenue
- Total Profit
- Profit Margin %
- Total Orders
- Average Order Value

## Key Business Insights
- **Electronics** is the highest revenue-generating category
- **Home & Furniture** delivers the highest profit margins
- **East region** leads all regions in total revenue
- Year-over-Year comparison reveals growth trends across 2023–2024

## Features
- Interactive slicers (Year, Region, Category)
- Year-over-Year time-series analysis
- Cross-filtering across all visuals
- Multi-page navigation menu
- Consistent professional color theme

## Tools Used
- Power BI Desktop
- DAX (Data Analysis Expressions)
- Power Query
